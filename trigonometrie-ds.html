Exercice 3 — Angles associés 4 points

  1. Simplifier, pour tout réel x :  A(x) = cos(π − x) + cos(−x) + sin(π2 − x).

Exercice 1 / 4

1. 120° = 120 × π180 = 2π3  ;  225° = 225 × π180 = 5π4. [1 pt]

2. 5π6 = 5 × 180°6 = 150°  ;  7π12 = 7 × 180°12 = 105°. [1 pt]

3. 7π6 = π + π6 (en bas à gauche) ; 11π2 = 6π − π2, donc D est au même point que −π2 (en bas). [0,5 pt par point]

Exercice 2 / 4,5

a) 17π6 = 12π6 + 5π6 = 2π + 5π6. Mesure principale : 5π6.
cos = cos(π − π6) = −√32  ;  sin = sin(π − π6) = 12. [1,5 pt]

b) −13π4 = −16π4 + 3π4 = −2 × 2π + 3π4. Mesure principale : 3π4.
cos = −√22  ;  sin = √22. [1,5 pt]

c) 2026 = 3 × 675 + 1, donc 2026π3 = 675π + π3 = 674π + 4π3 = 337 × 2π + 4π3.
Or 4π3 − 2π = −2π3. Mesure principale : −2π3.
cos = −12  ;  sin = −√32. [1,5 pt]

Exercice 3 / 4

1. A(x) = −cos x + cos x + cos x = cos x. [1,5 pt]

2. B(x) = −sin x − (−sin x) + (−sin x) = −sin x + sin x − sin x = −sin x. [1,5 pt]

3. 4π5 = π − π5 donc cos(4π5) = −cos(π5) ; de même 3π5 = π − 2π5 donc cos(3π5) = −cos(2π5).
Les termes s'annulent deux à deux : C = 0. [1 pt]

Exercice 4 / 3,5

1. cos²x = 1 − sin²x = 1 − 925 = 1625, donc cos x = 45 ou cos x = −45.
Comme x ∈ [π2 ; π], cos x ≤ 0, donc cos x = −45. [1,5 pt]

2. sin²x = 1 − cos²x = 1 − 19 = 89, donc sin x = √83 = 2√23 ou sin x = −2√23.
Comme x ∈ [−π ; 0], sin x ≤ 0, donc sin x = −2√23. [2 pts]

Exercice 5 / 4

1. cos x = cos(π4) ⇔ x = π4 ou x = −π4 (à 2π près). Dans ]−π ; π] : S = { −π4 ; π4 }. [1 pt]

2. 2 sin x + 1 = 0 ⇔ sin x = −12 = sin(−π6) ⇔ x = −π6 ou x = π + π6 = 7π6 (à 2π près).
7π6 − 2π = −5π6. Dans ]−π ; π] : S = { −5π6 ; −π6 }. [1 pt]

3. cos x = cos(2π3) ⇔ x = 2π3 ou x = −2π3 (à 2π près). Dans [0 ; 2π[, −2π3 devient −2π3 + 2π = 4π3.
S = { 2π3 ; 4π3 }. [1 pt]

4. sin x = sin(π3) ⇔ x = π3 + 2kπ ou x = 2π3 + 2kπ, avec k ∈ ℤ (car π − π3 = 2π3). [1 pt]

Bonus + 1

Soit M le point du cercle associé à π3 et I(1 ; 0). OI = OM = 1, donc OIM est isocèle en O avec un angle au sommet de 60° : ses deux autres angles mesurent aussi 60°, il est équilatéral.

Le projeté H de M sur (OI) est le pied de la hauteur issue de M, qui est aussi la médiane : H est le milieu de [OI]. Donc cos(π3) = OH = 12.

Puis sin²(π3) = 1 − 14 = 34, et sin(π3) > 0, donc sin(π3) = √32.
